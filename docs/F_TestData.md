## 5. 数据分析要点

1. **规模效应（电梯数）**：同 200 人，N=3 均等 133.6s → N=6 65.0s → N=24 14.9s（N 增 8 倍，均等降约 91%）
2. **规模效应（楼层数）**：同 200 人，L=20 均等 65.0s → L=80 126.1s（楼层增 4 倍，均等增约 94%）
3. **容量影响**：cap=4 均等 65.0s → cap=2 97.6s（容量减半，均等增约 50%）
4. **客流梯度**：λ=0.2 均等 3.9s/积压 2 → λ=1 均等 13.2s/积压 43 → λ=4 均等 63.1s/积压 787（积压随客流急剧上升，符合有限调度能力边界）
5. **满载与空闲**：高客流下满载秒接近总工作时间（如 random_high E3 满载 156.9s/空闲 0.10s），说明电梯长期处于满载运行
6. **确定性**：全部场景固定种子，可精确复现
